# Yoop - Social Media Platform

Yoop is a comprehensive social media platform designed with modern web technologies to provide a seamless and engaging social networking experience.

## Key Features

- **Interactive News Feed** - Share posts, photos, videos and engage with content
- **Real-time Messaging** - Private conversations with real-time updates and typing indicators
- **Stories & Reels** - Share temporary content and short-form videos
- **Groups & Communities** - Create and join communities around shared interests
- **User Profiles** - Personalized profiles with customization options
- **Collections** - Save and organize posts in custom collections
- **Marketplace** - Buy and sell items within your community
- **Progressive Web App** - Works offline and can be installed on mobile devices

## Technology Stack

- **Frontend**: React, TypeScript, TailwindCSS, Shadcn UI
- **Backend**: Node.js, Express
- **Database**: PostgreSQL with Drizzle ORM
- **Real-time Communication**: WebSockets
- **State Management**: TanStack Query
- **Animation**: Framer Motion
- **Authentication**: Passport.js with session management

## Getting Started

### Prerequisites
- Node.js 16+ and npm
- PostgreSQL (optional - uses in-memory DB by default)

### Installation
1. Clone the repository
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`
4. Open http://localhost:5000 in your browser

## Project Structure

- `/client` - React frontend application
  - `/public` - Static assets and PWA resources
  - `/src` - Source code
    - `/components` - Reusable UI components
    - `/hooks` - Custom React hooks
    - `/pages` - Application pages
    - `/lib` - Utility functions
- `/server` - Express backend
  - `/routes` - API endpoints
  - `/storage` - Database models and queries
- `/shared` - Shared types between frontend and backend
